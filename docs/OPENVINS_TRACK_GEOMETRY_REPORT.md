# OpenVINS 特征轨迹几何审计（开发世界 1701）

**结论：同一批 183 次清理后的特征窗口尝试，在离线 PX4 EKF2 位姿参考下，178 次能三角化为正深度，5 次为负深度；而原版 OpenVINS 仍是 178 次线性三角化失败、5 次细化失败、零视觉更新。** 这说明图像轨迹并非普遍完全不可解，也提示 OpenVINS 内部的相对位姿、时间同步或暂定相机–IMU 标定值得继续查证。它不证明任何一种特定根因，更不代表 VIO、EKF2 视觉融合或飞行安全门槛通过。

本轮没有重跑 PX4/Gazebo、训练策略或改变场景。使用前轮纹理开发世界 `1701` 的 604 张 RGB、同一份 15,107 条 IMU 的 PX4 ULog、相同输入顺序与 OpenVINS 配置；在独立的上游 OpenVINS `69488123ed9362dd44b6f28e7f4680abbff1442b`（GPL-3.0）检出上增加了**仅写日志**的补丁，输出克隆时间清理之后的归一化图像坐标。新重播 `states.csv` 的 SHA-256 与未插桩的配置 v2 重播及上一轮诊断完全相同，都是 `f0f1966527c80bc49a5d219053a3e9c282aeb04eab7439dccd0fe3d265f8740f`。183 次窗口尝试有 1001 个观测、174 个不同的特征 ID；重复 ID 依然计作不同尝试，未丢弃失败项。

离线脚本按 PX4 [VehicleAttitude](https://docs.px4.io/main/en/msg_docs/VehicleAttitude) 的 FRD 机体到 NED 地球四元数，以及 [VehicleLocalPosition](https://docs.px4.io/main/en/msg_docs/VehicleLocalPosition) 的 NED 位置、有效位和重置计数器，在各自的 `timestamp_sample` 上插值。超过 20 ms 的采样缺口、无效位置、重置边界和非有限值均拒绝跨越。1001 个观测均获得有效参考。使用原配置固定的相机到 IMU 旋转、`[0.12, 0, -0.002] m` 平移和约 108.124 px 焦距；不拟合时间偏移、外参或尺度。三角化采用世界坐标中的射线最小二乘，并记录每次尝试的深度、基线、条件数与重投影误差。PX4 EKF2 是由传感器融合得到的**离线参考**，会有自身误差，绝非 Gazebo 真值或 OpenVINS 的定位输出；参考位姿没有送回估计器。

|---|---:|
| 清理后的特征窗口尝试 / 离线记录 | 183 / 183 |
| 有效 EKF2 参考 / 未评分 | 183 / 0 |
| 正深度 / 非正深度 | 178 / 5 |

| 正深度轨迹的锚点深度中位数 | 3.70 m |

其中 5 次负深度尝试的特征 ID 与完整数值仍保存在逐条 CSV。正深度尝试里仅 87 次的本审计法方程条件数不超过 10,000；这个数**不能直接与 OpenVINS 自身条件数相等比较**，因为求解器、坐标及判据不同。29 次双观测轨迹可供几何检查，却缺少足够冗余来可靠排除误匹配。至少 3 次观测的 149 次中仍有明显高残差离群值（最大约 19.94 px），全部保留。固定外参虽然通过早前静态光学帧投影检查，但动态时间偏移仍未经标定；[OpenVINS 官方校准说明](https://docs.openvins.com/gs-calibration.html)也要求足够的平移和多轴旋转激励，本开发飞行不构成完整动态标定。

**下一项单独假设：** OpenVINS 在这些观测时间使用的克隆相机相对位姿与 PX4 EKF2 参考存在方向、尺度或时间演化不一致。后续可在同一保存数据上只导出克隆位姿，比较短窗口相对旋转、平移方向及基线随时间变化；保持上游参数、图像和 IMU 不变，不把 EKF2 当成轨迹真值喂入滤波器。若差异显著，再分别查 IMU 帧/时间偏移、初始化和外参，避免同时改多个因素。

`evidence/openvins-track-geometry-dev-1701-verified.zip` 保存插桩补丁与脚本、完整日志、逐次审计 CSV/JSON、状态哈希对应文件、配置、离线工具和本报告；相邻 `.sha256.json` 是逐文件索引。前轮 `evidence/openvins-texture-dev-1701.zip` 已保存原始 18.1 MB ULog 与输入图像，本包用其哈希引用，避免重复提交。诊断共享库约 293 MB，没有并入 Git；精确哈希、字节数及上游补丁保留在元数据。上述工作是**开发数据上的离线诊断**，不是 PX4 物理仿真中新 VIO 闭环，亦非 HITL、实飞或与 EGO-Swarm 的正式对照。五机 WSL2 RTF 约 0.873，仍低于 0.95 的容量门槛，本轮未改变该结果。

审计器与合成几何测试覆盖固定坐标变换、姿态/位置插值、无效及重置拒绝、已知点、误匹配和不可评分失败保留：针对性测试 **8/8 通过**，Ruff 与 `git diff --check` 通过。完整项目回归使用当前工作树的 `src` 设置 `PYTHONPATH` 后为 **333 passed、1 warning**（176.24 秒）。首次未设置该路径时，系统里另一个 FlyDrones 工作树的可编辑安装导致 28 个测试收集导入错误；更正环境后没有测试失败。唯一警告是既有 Malecns 数据的神经元组无匹配项。
