# OpenVINS 起飞前纹理板单机开发实验（2026-10-04）

**结论：场景接入成功，预解锁视觉特征库出现大量特征，但固定的 OpenVINS 仍未在预解锁静止窗口初始化；完整果蝇控制回合越界。**本结果只是一台 PX4/Gazebo 物理仿真无人机的传感器采集和一次离线 VIO 回放。OpenVINS 输出未送入 PX4 EKF2，也没有证明真实相机 VIO、故障恢复、多机安全、HITL 或实飞。

## 固定输入与隔离

从原公开开发场景 seed 1701 精确派生两个有相同视觉和碰撞几何的静态板，位置为 `x=[-5.52,-5.48] m`，`y=[-1.55,-0.75]` 和 `[0.75,1.55] m`，`z=[0.1,1.4] m`。中心通道宽 1.5 m，`has_route` 通过，`gz sdf -k` 返回 `Valid`。原场景 JSON/SDF SHA-256 为 `af449cf3...` / `7a40320c...`；新 JSON/SDF 为 `e783db3d...` / `2ffb317a...`。地面和障碍贴图 SHA-256 `5e628279...` / `28f87e79...` 与之前开发场景相同。改动是**物理环境变化**，不属于正式冻结的 20 场景，也不能用作公平的控制器对照。

PX4 源码 `d6f12ad1c4f70ad3230afd7d86e971421e02fef4`、二进制 SHA-256 `e8af7cba...`；OpenVINS 上游 `rpng/open_vins@69488123ed9362dd44b6f28e7f4680abbff1442b`，使用原有仅增加初始化逐帧日志的库 SHA-256 `532ae57a...`；离线 runner `bf811d14...`，估计器配置 `eaa40224...`。完整果蝇模型 `b6be8b3d...`、训练读出 `dac766e3...`，未改策略、PX4、相机标定、速度约束或安全处理。所有完整哈希和可重放依赖分别见夹具及 `dependencies-v1/manifest.json`；本机约 293 MB 的动态库和 81 MB 的果蝇模型未放入证据 ZIP，故仅凭 ZIP 不能逐字节重新执行整个实验。

隔离工作树起初缺少模型文件和训练读出。两次启动均在加载控制器时失败，**没有启动实际 PX4/Gazebo 回合**；错误日志和部分输出目录保留在证据中。随后从原项目按 SHA-256 校验复制依赖，使用全新 `episode-run-v3` 做唯一一次实际 PX4/Gazebo 采集。任何旧结果均未覆盖。

## 采集与相机接入

采集进程退出码 0 只表示记录完成。回合状态为 **`out_of_bounds`**，路径末端 `(8.665,-8.024,1.293) m`，记录的最小净距 0.074 m，无接触事件；607 次完整果蝇决策的墙钟中位数 0.482 s、P95 0.522 s，远超 50 ms 控制步。采集墙钟 402.1 s，仿真从零至 63.35 s，粗略 RTF 0.158。物理步在决策期间暂停，不是实时机载性能证据。采集了 634 张 RGB、634 条相机信息和一份 18,227,325 字节的有效 ULog，三项采集核验均通过；进程结束后确认该回合 PX4/Gazebo 已释放。

预解锁时间 `15.618–19.642 s`，完整窗口有 40 张连续 RGB（最大间隔 0.1 s）和 1,006 条 PX4 `sensor_combined` IMU（最大间隔 0.004 s）；末两秒的 PX4 EKF2 `vehicle_local_position` 样本 250 条、速度状态均有效、无计数器变化，中位速度 0.0167 m/s，P90 0.0181 m/s。**EKF2 是融合估计，不是独立真值。**40 张预解锁图像的哈希只有一种，与静止画面一致。同一 18.0 s 图像对比之前封存的 seed 1701 原场景，左右侧出现两块新的暗色板；有 4,440 个像素改变，变化框 `(9,6)–(151,66)`。这证实板进入实际相机画面，不代表表面纹理已经形成足够可持续跟踪的轨迹。

## 固定 OpenVINS 回放

从这一个 ULog 和原始 RGB 导出 15,203 条 IMU、608 张落在 IMU 时间域内的图像，使用固定 runner、配置和逐帧日志库**回放一次**。严格逐帧解析得到 255 次初始化尝试。预解锁 40/40 帧均有初始化尝试，特征库中位数 207（之前原场景逐帧诊断为 0），但初始化器前/后半时间窗可用轨迹数各最多只有 **9**，未达未修改的 **15/15** 门槛。OpenVINS 上游日志在 **28.0 s** 帧记录 `ready`、静止初始化器和成功事件，已晚于预解锁结束 8.358 s；异步运行器直到 **28.5 s** 才首次输出已初始化状态，晚 8.858 s。针对内部初始化事件重算的 26.0–28.0 s PX4 EKF2 速度窗口有 251 条有效样本，中位数 **0.0351 m/s**、P90 **0.187 m/s**，28.0 s 端点速度 **0.212 m/s**；前段较静止、末端已运动，不能宣称整个窗口满足静止前提。旧 `prearm-audit-v1` 自动审计以首个输出状态 28.5 s 为中心，其 26.5–28.5 s 速度中位数 0.139 m/s、P90 0.244 m/s **不是内部初始化窗口**；校正后的时钟和逐样本审计见 `internal-init-audit-v1/`。离线插桩先前在原始输入上验证过状态字节不变；**本次新输入没有另跑无插桩版本做同输入奇偶性核对**，因此只报告此一次插桩回放。

回放后有 349 张初始化状态帧，46 帧记录非零 MSCKF 更新、合计 68 个特征更新。与仅在评分时读取的 Gazebo 轨迹做无缩放刚体对齐，304 个重合帧的 ATE RMSE 约 **0.642 m**，P95 约 1.430 m，末端误差约 1.941 m。原开发回合曾得到 368.08 m，但环境、碰撞和飞行路径均已改变，**不能把两个数字之差归因于板或宣称算法已修复**。从飞行开始到 VIO 初始化前仍没有可用 VIO；本次也未做 VIO→EKF2 闭环、VIO 健康门限或故障注入。
