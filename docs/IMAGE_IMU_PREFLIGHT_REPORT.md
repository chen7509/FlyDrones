# 单机模拟 RGB+IMU 数据预检（2026-10-01）

本阶段为真实 VIO 接入准备**原始数据入口**，没有产生 VIO 位姿、协方差或 PX4 外部视觉融合。当前控制器仍使用由 Gazebo 模型真值生成的里程计和相机位姿，结果 JSON 明确写有 `odometry_source=gazebo_model_truth`。只使用既有开发世界 `1701`，没有重跑、筛选或调参于已冻结的 20 个正式世界。

实现了可选 `--record-rgb`：在 Gazebo 图像消息回调中保存原始 160×120 RGB 字节为无损 PPM，逐帧保留消息头仿真纳秒时间、SHA-256；重复或逆序时间及写入错误会计数并使可选采集门槛失败。同回合的 PX4 ULog 在进程退出后保存。分析脚本先复核帧/ULog 哈希，再读取 `sensor_combined` 三轴角速度、加速度与时间戳，**不移动或拟合时间轴**，分别报告全部帧和 IMU 覆盖区间的最近邻差值。

实现后本分支全套回归 305/305 通过，相关 Python 文件 Ruff 检查通过。采集与测试均未启动第二个并行 PX4/Gazebo 回合。

| 指标 | 单次开发结果 | 判断 |
|---|---:|---|
| 任务终局 | `out_of_bounds` | 策略失败，不能称任务通过 |
| RGB 图像 | 512 帧，10 Hz 中位帧率；逆序/重复 0 | 图像采集可复核 |
| PX4 `sensor_combined` | 12,107 条；ULog 14,533,046 字节 | ULog 可解析，含三轴 IMU |
| 图像落在 ULog IMU 时间范围内 | 484/512 | **28 帧缺少配对范围**，完整数据门槛未通过 |
| 最近 IMU 时间差 p95 | 全帧 109 ms；覆盖区间内 0 ms | 后者仅是共享仿真时间网格的观察，不是传感器延迟或校准证明 |
| 仿真任务时间 / 墙钟 | 22.1 s / 286.42 s | 运行中控制器计算时仿真暂停，不能推断实时性 |

相机最早时间 0.002 s，ULog IMU 最早 2.664 s。复核本机 PX4 `rcS` 发现 `SDLOG_MODE` 已默认设为 1；同回合 `px4.log` 显示 `logger started (mode=all)` 在解锁前，故此前“默认解锁后才开始记录”的归因**不成立**。当前后端先启动 Gazebo 并持续推进世界，然后才启动 PX4；PX4 日志首次设置 lockstep 时的仿真时间约为 1.737 s。以这两个原始日志时间边界重新计算 512 帧：18 帧早于 PX4 首次 lockstep 时间，9 帧位于该时间和首个 ULog IMU 样本之间，484 帧位于 IMU 范围内，另有 **1 帧晚于末个 IMU 样本**。因此“28 帧全是启动时缺失”的说法也不准确；这些时间分段不等于相机-IMU 外参或时钟校准。下一开发试验应保留全部原始帧并分别报告首尾覆盖，不能删帧冒充本次完全覆盖。全部 527 个原始文件（帧、世界、路径、日志、ULog、清单、时间分析和健康摘要）归档于 `evidence/fly-ego-vio-preflight-1701.zip`，逐文件哈希见同名 `.sha256.json`；ZIP SHA-256 是 `e74a7a7e4af17c9f8c53d5c7067d4c1c3ee9309bd1c6487d82d4d95b4e21efeb`。ULog SHA-256 是 `eb0a97b253002df1b3285dfd195ce8c0a0e3ec8b9b2c3dec9921392ae2c219a8`。同回合 ULog 基本主题门槛通过，EKF 滤波故障与 PX4 failsafe 样本为 0，但任务仍越界且外部视觉位置融合样本为 0。

候选算法沿用[阶段证据台账](https://github.com/chen7509/FlyDrones/blob/codex/px4-sensor-readiness/docs/PROJECT_EVIDENCE_LEDGER_2026-10-01.md)中的上游调研：OpenVINS 可用单目图像+IMU，但 GPL-3.0 需商业许可证评估；Basalt 为 BSD-3-Clause、主要使用双目+IMU，现有单路 RGB-D 模型不能按名称冒充双目标定。两者均未在此数据集构建或运行。下一门槛是完整 IMU 覆盖、真实相机内参和相机-IMU 外参及时间校准、可核验上游 VIO 输出和协方差、PX4 EKF2 融合及掉帧故障验证；最后再量化 WSL 单机/五机性能。原五机相机容量均值约 0.873 RTF，低于 0.95，仍是失败而不是果蝇策略失败。
