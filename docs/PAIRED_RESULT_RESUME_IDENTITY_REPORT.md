## Scope and limits

This check verifies supplied result declarations against the requested pair. It cannot authenticate the process, prove the same physical state/map/clock was consumed, validate all dynamics/sensors/safety conditions, or certify the upstream algorithm. Existing freeze/file and ULog checks are retained, not replaced. The minimal test freeze and world documents are deliberately constructed fixtures and are not a qualified frozen experiment. The legacy report still requires Gazebo-model-truth labels, so it remains outside the original trusted-source/full-MaleCNS comparison goal. No legacy truth result is promoted to VIO, teacher or training data.

Preflight is an observed scan, not an atomic snapshot against hostile concurrent replacement. Later rereads are checked, but a caller can change other files after the scan; no adversarial filesystem security claim is made. This repair does not verify formal job/seed-manifest cardinality, duplicate world identities, complete runtime closure, additional fair baseline implementations or reported outcome authenticity. A matching terminal failure still counts; a matching declared success is not independently proved by this helper. The full learning/physical gates and all historical failures remain unchanged. The goal panel is still blocked and is not rewritten as active or complete.
