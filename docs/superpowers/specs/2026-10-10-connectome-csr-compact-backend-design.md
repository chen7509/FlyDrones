# Optional compact fixed topology for the full connectome

The full MaleCNS remains 166,700 neurons and 25,582,837 signed connections. Its current training core stores a COO fixed matrix plus four redundant per-edge buffers. This stage adds an **explicit opt-in** CPU CSR `int32` representation for the same signed, row-normalized fixed topology. It does not prune connections, train weights, change the four trainable parameter groups, change the default runtime, or label a derived student as the full model.

PyTorch 2.14 [documents CSR × dense sparse matrix multiplication with backward support for both operands](https://docs.pytorch.org/docs/stable/generated/torch.sparse.mm) and [accepts 32-bit CSR index tensors](https://docs.pytorch.org/docs/stable/generated/torch.sparse_csr_tensor.html). On this host, a three-neuron fixture matched the existing COO output, recurrent state and all four trainable parameter gradients to `1e-7`. The result is only a small CPU feasibility check. PyTorch still warns that sparse CSR support is beta; no full-graph performance conclusion follows.

`ConnectomeConstrainedCore(..., topology_format="coo_reference")` retains the existing constructor behavior and buffers. `topology_format="csr_compact_v1"` builds one canonical CSR fixed matrix with `torch.int32` row pointers and columns and `torch.float32` values; it does not retain `edge_row`, `edge_column`, `edge_sign` or `edge_magnitude` as model buffers. It rejects unknown formats, non-finite weights, dimensions or connection counts beyond signed 32-bit index range, and malformed source topology. Construction still compares the full canonical topology identity against the parameter artifact before any backend selection. The compact path must preserve orientation `(post, pre)`, signs, duplicate coalescing, zero elimination and the **reference order of operations**: normalize raw edges against their row's raw absolute sum, then coalesce duplicates. Its fixed matrix never receives gradients. Trainable parameter names and checkpoint payloads remain unchanged because checkpoints save named trainables only.

The compact path stays opt-in for tiny parity tests and future bounded full-graph studies. `curriculum_session` and `load_inference_core` keep their current default until the pinned full MaleCNS graph is actually loaded, its identity and forward/gradient parity checked, and pre/post memory plus latency measured under a prospective resource profile. A small fixture or static byte formula cannot qualify full training, P95 latency, VIO capture or flight safety. The 4 GiB full-model probe gate remains in force unless independently remeasured and revised through a separate, named study.

The static fixed-buffer estimate at 25,582,837 edges is 1,125,644,828 bytes for present COO plus four per-edge buffers versus 205,329,500 bytes for a CSR-only int32 matrix: a possible 920,315,328-byte reduction **after construction**. This excludes SciPy source storage, canonical identity calculation, temporary arrays, autograd states, image features, the OS and allocator overhead. Peak RAM and end-to-end decision latency remain unverified.
