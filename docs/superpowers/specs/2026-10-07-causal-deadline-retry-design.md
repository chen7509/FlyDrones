# Causal deadline physical retry package

## Purpose

Create a new prepare-only package after the fixed-input causal wall-deadline correction. The package must preserve the immutable `study-v8/capture-v1` failure and bind both its independent audit and the correction evidence. It must not execute a simulator or reuse the failed destination.

## Inputs and invariants

Consume the audited `study-v8` package, its failed capture, outer completion record, attempt audit, and the sealed causal-deadline correction archive/audit. Require the attempt classification `causal-input-wall-deadline-platform-scheduling-refusal`, zero motion/force, closed fusion and VIO gates, no ULog, worker exit 2, empty post-run resources, and a clean correction audit with no physical execution claim.

The new runtime binding must recompute every declared file hash from current committed files and add the builder, independent auditor, correction archive/audit, failed attempt audit/completion, and correction design/plan as evidence. The execution contract must retain the exact 25 s / 1 ms / 250 Hz / 10 Hz 160×120 workload, original vehicle, motion/force profile, safety limits, OpenVINS binary/config, native reference, 300 s worker/supervisor limits and launch environment. Only paths to the new package and destination may change.

## Gates

The output contains no capture directory and every downstream qualification remains false. An independent auditor recomputes the binding, execution contract and command, verifies all source/correction evidence, and rejects any workload drift, missing or extra member, pre-existing destination, active competing resource, or false qualification.

After the builder and auditor pass, commit the code and package metadata, then re-audit from the committed tree. A current-code startup preflight must pass at a separately named destination before any physical run. A later physical target is limited to one new destination; failure is retained and never overwritten.
