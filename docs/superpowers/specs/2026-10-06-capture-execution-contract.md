# Capture execution contract and declared artifact snapshots
## Intent and scope
Prevent PR48 prospective metadata drift, preserve all historical evidence. This stage supplies shared enforced limits and a strict declared-file snapshot utility, with read-only installed inventory. It does not qualify complete runtime closure or launch a new physical study. User standing authorization covers design and inline execution.
## Design
Use execution_contract(args) as the single source for capture worker limits, supervisor limits and launch metadata. Ordinary wall/supervisor300/300; reference fault60/90. Duration25s, physics1ms, IMU250Hz, camera10Hz160x120 retained. Profile fields and estimator/reference selection included. Optional --execution-contract validates exact JSON types/keys/values before any launch, and the same declaration travels to worker; legacy commands remain supported with explicit undeclared status. A reusable declared launcher requires this flag. Unknown extra keys, booleans for integers, float substitutions, mismatches and duplicate JSON keys refuse. No safety TTL change.
Declared snapshot records requested path, resolved path, symlink chain, device/inode/size/mtime/ctime, sha256, with fd and path comparison before/after. Require nonempty category->nonempty file lists and unique normalized requested paths. Missing/unreadable/nonregular files, path/link drift, dependency-command failure or malformed/missing ldd output refuse. Shared resolved targets across distinct aliases allowed and recorded. Write exclusive complete JSON with short-write/flush/close failure propagation; interrupted file is not success and is not overwritten.
Snapshots prove only declared files at read times. Unknown plugins/dlopen/environment remain explicitly unqualified; hashes are not a hostile-filesystem security boundary. No historical missing hash backfill. Fixed native/config retain exact bytes. Runtime capture integration of full closure and gauge protocol remain next gates.
## Tests and acceptance
Synthetic contract mismatch must prevent supervisor invocation; actual supervisor receives300/90 as appropriate. Worker uses same contract duration/wall values. File mutation during read, missing file, duplicate, link drift, IO shortwrite/close, malformed ldd and before/after drift refuse. Real WSL read-only inventory locates installed bindings/startup files; no active resources before/after. Full regression plus independent review before draft publication. Physical/VIO/fusion remain untested.
