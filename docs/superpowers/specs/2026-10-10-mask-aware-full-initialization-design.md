# Mask-aware full MaleCNS initialization

The 15-channel `depth-mask-v3` learner has no full-model parameter artifact. The legacy `--initialize-full` path maps 17,268 sensory neurons onto 12 channels and loads a 25,582,837-edge connectome, which is unsuitable for the current low-memory host. Create a **new, untrained** v3 initialization from the previously frozen full-model parameter artifact without constructing that graph. Preserve the old artifact byte-for-byte.

Only the source artifact with the recorded manifest and array SHA-256 values is eligible. Verify its manifest, its own array hash, the pinned source model file hash, full identity, ordered legacy features and outputs, default untrained numeric values, and the deterministic modulo-12 mapping. Reuse the exact identity and neuron indices. Assign the existing sensory neuron indices deterministically across all 15 ordered v3 channels using index modulo 15; initialize gains, bias, time constant, and readout anew through `initial_parameter_set`. The modulo assignment is an engineering initialization, not anatomical evidence or learned weights. Save to a separate destination with the existing no-overwrite writer; reload and verify its mapping and identity.

This does not verify the full topology anew: its topology digest is inherited from the frozen legacy builder. Streaming the pinned model file hash verifies source bytes without loading its graph. The result is **initialization only**. It is not a trained policy, non-truth observation corpus, latency measurement, safety qualification, or PX4 flight result. Full training remains gated by memory and a genuine non-truth v3 corpus.

Use TDD on the derivation: valid mapping/identity and all 15-channel coverage; reject trained or malformed source parameters, wrong profile, tampered source artifact/model, existing destination, and load/save mismatch. Run focused tests and changed-file lint; do not start Docker, PX4, Gazebo, or full MaleCNS training.
