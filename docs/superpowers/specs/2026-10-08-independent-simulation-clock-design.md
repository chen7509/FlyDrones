# Independent simulation-clock evidence

The full goal needs a sensor-derived VIO clock that can be related to PX4 without using the request being checked as its own reference. This stage adds a reusable PostUpdate consumer, tested synthetically, not a live transport or flight study. User preapproval covers this routine design and execution.

## Evidence and choice
Pinned PX4 d6f12ad GZBridge subscribes to /world/<world>/clock. First callback sets REALTIME; subsequent callbacks set MONOTONIC. Under ENABLE_LOCKSTEP_SCHEDULER, drv_hrt maps this into the scheduler and hrt_absolute_time reads its microsecond time. Refetched bytes equal the prior sealed source; a web-rendered line count is not byte-comparison evidence. BSD3. Current capture post_update reads UpdateInfo.sim_time into a latest-value dictionary; it does not establish arrival or journal availability. Gazebo UpdateInfo documents iterations, dt, paused and simTime. Gazebo Sim is Apache2. Sources/metadata/hashes in results/openvins-independent-clock-dev-1701. No algorithm changes or new paper claims.

Choose direct PostUpdate observation from the already owned TestFixture. It adds no subscription or dependency. A second transport clock subscriber would add discovery, queue and callback ownership ambiguities. Request ts1, wall-time extrapolation and pose-derived time are rejected. A TestFixture callback is independent of the MAVLink request, but does not prove when PX4 consumed its own clock subscription.

## Fixed contract
New tools/benchmark/openvins_simulation_clock.py exposes JournaledSimulationClock(session_id, now, journal, start_ns, guard), post_update(info, ecm=None), snapshot(received_ns), check(), and evidence. Single immutable session; guard must return None, caller must bind it to actual owned lifecycle. Tokens and guards do not prove ownership. No replace/reset in place: a reset requires a new lane and new downstream clock session.

This is the existing zero-origin 25s study: exact Python datetime.timedelta sim_time/dt, dt=1ms, iteration1/time1ms first, subsequent consecutive iteration and exact1ms increments, paused exactlyFalse. At most25000 observations. Reject partial attachment, gaps, equal/regressed/jumped time, pause, malformed types and excess samples. No rounding or manufactured samples. Wall clocks are strict integer monotonic nanoseconds; ties allowed, ages>=2s refused. Source age uses callback entry, never a later journal completion. Existing bootstrap8s and500sample requirements stay with their existing owner and are not extended here.

Separate immutable observation fields: iteration, sim_ns, callback_ns and journal_return_ns. Callback enters with a local clock read before accessing info; successful journal(None return) precedes publication. Journal stores attempted source observation; return time and accepted/refused status live in exported evidence, since a record cannot contain the future time of its own completed write. No fsync, durability or bounded arbitrary Python callback claim.

Only one post_update may execute at once. A state lock protects short transitions; slow journal runs outside it. Readers may use the prior committed sample while a new one is pending and younger than2s; no pending sample is released. Missing first sample refuses. Concurrent writers/reentry, guard/clock/journal failure latch refusal. An in-flight consumer may have obtained a previously healthy snapshot before a later fault; caller must recheck before a side effect. No retrospective cancellation claim.

snapshot returns a ClockSelection(observation, received_ns, selected_ns). It selects current committed simulation time at reply preparation, which may be observed after packet receipt. It is not the simulation time at receipt, and never reads ts1. Repeated snapshots do not fabricate a newer observation; RemoteMonotonicClock still rejects same-sample reuse for successive TIMESYNC replies. No interpolation, kernel-arrival timestamp or PX4 clock equality claim. Every runtime-source/network/fusion qualification stays false.

## Validation and remaining gate
Synthetic normal callback and actual RemoteMonotonicClock composition; input type/gap/pause/reset/freshness, delayed/failing journal, reader during writer, concurrent writers, return timestamp ordering, mutation, bounds. Targeted regressions include receiver, remote clock and wire/bootstrap tests where dependencies exist. No new socket, TestFixture, PX4, estimator, training or physical study. Existing capture is not silently opted in. Remaining owned descriptor/session and actual callback binding must be designed and verified before a live study; this stage cannot authorize it.
