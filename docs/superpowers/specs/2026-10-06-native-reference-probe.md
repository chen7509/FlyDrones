Standing authorization; reuse existing isolated workspace. New research condition supported-ready-native-reference-v1, sensor-only, same supported-ready-v1 force/timing and source gates. Goal is fresh diagnostic reference and failure containment, not VIO or flight qualification.

Research selected a pybind11 native extension invoked synchronously by existing TestFixture System callbacks instead of a separately scheduled System plugin. Installed pybind11-dev2.11.1 BSD3 and Python3.12/gz-sim8.15 already exist. ABI spike53464d5a successfully consumed an ECM created by gz.sim8 without simulation. Separate plugin Stop signaling and wholesale middleware upgrades are rejected as additional lifecycle cost.
