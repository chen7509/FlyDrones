## Design

Facade and native backend latch first failures. Gateway refuses restart/advance/observe after failure until new instance; duplicate active start refuses. On shape/backend advance failure, stop_motion on native backend (or close on non-native injected backend), preserve primary exception and secondary cleanup error. Existing valid speed/acceleration/yaw limits unchanged. Shape validates exact dimensions, finite scalar values/previous state/positive limits and finite acceleration step; stable vector norms prevent overflow artifacts. Invalid previous speed outside declared bound refuses rather than outputting above limit. Accept ordinary NumPy numeric scalars used by existing fullFly adapter, reject bool/text/huge nonrepresentable values.

Native four-SI-value inputs are finite float32-representable before any motion publication; no additional v_max clipping/scaling. _send_local_ned calls existing public require_position_observation before heartbeat/send, still uses exact original LOCAL_NED/mask. Numeric/source/transport errors stop the stream, latch original error, notify waiters, and independently attempt LAND once if flying; LAND errors retained without replacing primary. If legacy source guard already requested LAND and flying=false, do not claim another native LAND or actual landing. No force-disarm/kill and no claim LAND ACK.

Condition protects pending/generation/ack/failure; a dedicated RLock serializes native MAVLink source/read/send/LAND and heartbeat drains. Failure latch is published/notified before best-effort LAND. No condition held while telemetry source callback runs. Recheck stop/failure before wire submission. An already admitted synchronous send or physics step can finish; no hard realtime cancellation claim. Pending wait cannot return success merely because stopped, cannot accept missing/dead worker or expired acknowledgement, and propagates failure with original cause. Publisher failure cannot advance ack. Native.advance checks before/after admitted physics step; if error discovered during run, retain that step's evidence and prevent subsequent steps.

stop_motion records phase/error/land attempt/result without simulator truth. Records and closed/failure flags are software observations only. Source gate is the existing0.5s decode/progression policy, not network arrival/generation, clock/health or calibration proof; slow/paused simulation refusal is a platform/observation result, not fruit strategy failure. Existing backend observations still explicitly model_truth-derived; this stage does not replace/qualify them or authorize fair teacher/training/realVIO.
