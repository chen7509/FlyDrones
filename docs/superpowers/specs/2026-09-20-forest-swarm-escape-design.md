# 100机森林逃生与集合设计规格

日期：2026-09-20

## 目标

在现有森林和100机去中心化模拟基础上建立一个联合场景：100架无人机从森林内部的安全位置起飞，依靠起飞前装入本机的航路、本地障碍感知和本地邻机观测穿过树林，离开森林后在东侧空地组成心形。正常飞行闭环不接收中央位置指令。

本阶段证明任务结构和控制接口在计算机模拟中可行，不代表已经满足真实商业演出的适航要求。

## 成功标准

- 场景内恰好有100架无人机，并且所有起点位于森林边界内。
- 起点不得位于树干、树冠、岩石或倒木的膨胀安全区内。
- 运行期间树木及其他静态障碍碰撞为0。
- 运行期间机间物理接触为0。
- 中央飞行指令计数始终为0。
- 120秒内至少95架越过森林东边界 `x > 12.5`。
- 120秒内至少85架进入各自心形目标点0.35米容差。
- 独立坐标复算的机间椭球安全系数不小于1；未解决安全区违规为0。
- 相同随机种子生成相同起点、出口分配、航路和结果。

## 场景几何

森林继续使用 `createForestWorld(42)` 生成的35组树木、6块岩石和1根倒木。原森林的水平范围为 `x ∈ [-12, 12]`、`y ∈ [-9, 9]`。

联合页面把可视地面向东延长至 `x = 25`。森林东侧 `x > 12.5` 视为已逃出区域。最终心形位于森林外，中心约为 `[18, 0]`，保证最左侧目标仍在东边界之外。

规划使用1.8米巡航高度。这个高度低于树冠主体，但树干、岩石和倒木仍作为障碍。障碍物在水平面按无人机半径和规划余量膨胀；任何与巡航高度相交的盒体都写入占用网格。

## 起点生成

规划器在森林内部按固定间隔扫描候选点，使用以下规则选择100个起点：

1. 高度固定为1.8米。
2. 点到所有有效障碍膨胀盒的距离满足规划安全余量。
3. 任意两个起点的水平间距至少0.82米。
4. 优先选择森林西部和中部点，使无人机需要实际穿越树林，而不是直接出生在出口附近。
5. 排序和选择过程只使用固定种子，禁止依赖对象遍历顺序或系统时间。

若当前森林几何无法产生100个合法起点，构造函数应抛出明确错误，不得把无人机放入障碍物或降低间距。

## 航路和出口分流

使用五个固定出口门，位于东边界外侧，纵向大致分布在 `y = -6、-3、0、3、6`。每架无人机根据起点纵向位置和出口当前分配数量，确定一个出口。

演出前，规划器在膨胀障碍占用网格上为每架机运行确定性的A*搜索。每架机获得一条自己的航路：

1. 森林内部起点。
2. A*生成的森林航点。
3. 对应出口门 `x = 12.5`。
4. 森林外过渡点。
5. 分配到的心形目标点。

A*只在演出准备阶段运行。飞行开始后，每架机只保存和推进自己的航点索引，不需要地面站继续规划或逐架发送位置。

路径允许删除共线点，但不得使用会穿过膨胀障碍区的直线捷径。目标分配继续使用确定性的距离匹配，避免大量交叉换位。

## 机载执行

新增 `ForestSwarmSimulation`，组合现有 `SwarmSimulation`：

- `SwarmSimulation` 继续负责本地邻机观测、预测避碰、下洗椭球和故障状态机。
- 森林层负责当前航点、出口状态、障碍感知、障碍接触计数和集合任务指标。
- 每架机到当前航点距离小于规定容差后，本机推进到下一航点。
- 穿过东边界后，本机状态从 `escaping` 变为 `rallying`，随后飞向自己的心形目标。
- 所有状态转换均由本机位置和预装任务决定，不使用全局“所有无人机已到达”信号。

森林障碍避免包含两层：

1. A*航路提供主要无碰路径。
2. 本地短距障碍安全层阻止无人机进入膨胀障碍盒，并记录干预次数。

第二层在本阶段属于理想化安全约束，页面和报告必须明确标注。原始几何碰撞应在约束修正前单独计数，不能通过位置修正把已经发生的接触隐藏为0。

## 去中心化与通信

- `centralMessages` 在联合场景中必须保持0。
- P2P状态广播可以出现延迟和丢包；任务航路和障碍安全层不得依赖地面链路。
- 邻机预测避碰继续只消费带时间戳的本地观测。
- 失联无人机继续执行已装入航路；定位丢失无人机保持最后安全点；低电量无人机停止任务并降落。

## 可视化

新增 `docs/forest-swarm.html` 和 `docs/live/forest-swarm-view.js`：

- 显示现有森林、100架无人机、五个出口门、森林东边界和森林外心形目标点。
- 无人机按 `escaping`、`rallying`、`arrived`、故障和降落状态着色。
- 面板显示逃出数量、集合到位数量、树木碰撞、机间接触、中央指令、本地避碰频率、实际最小椭球安全系数和障碍安全层干预次数。
- 提供暂停、重新试验、失联、定位丢失和低电量故障注入按钮。
- 明确区分带噪本地感知与理想化最终安全约束。

## 自动化验证

单元和集成测试至少覆盖：

1. 起点数量、森林范围、障碍间距和可重复性。
2. 五个出口均获得无人机，且每条航路存在并不穿过膨胀障碍。
3. 无中央指令时任务推进。
4. 树木几何接触在安全修正前计数。
5. 100机端到端逃出并集合。
6. 强风、P2P丢包、观测噪声和过期数据场景。
7. 三种单机故障不会恢复中央控制或破坏其他无人机的任务。
8. 独立于引擎报告，从最终坐标和每一步轨迹复算障碍侵入、机间椭球安全系数和到位数量。

## 已知边界与后续阶段

本阶段仍使用简化点质量动力学和理想化最终障碍约束，没有模拟桨叶下洗流场、真实相机遮挡、GPS/UWB误差分布、飞控饱和、通信协议栈或电池电压。通过后下一阶段进入PX4或ROS 2软件在环，以真实最大速度、加速度、制动距离、传感器视场和飞控延迟重复同一验收场景。
