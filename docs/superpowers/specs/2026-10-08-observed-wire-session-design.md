# Observed clock/receiver/owned-wire composition

The full goal needs genuine sensor/VIO timing and fail-closed PX4 transport. This architectural package joins the three existing interfaces into one usable offline-tested path. It does not register a simulator callback, launch a process/socket or authorize an actual UDP/PX4/ODOMETRY study. User preapproval covers routine spec/plan/implementation/publication.

## Research and choice
Reuse fixed PX4 d6f12ad (BSD3), pinned pymavlink2.4.49 (LGPLv3 API already selected), installed Python3.12.3 (PSF) and Gazebo8.15 (Apache2). Current clock-stage source/metadata and receiver-stage fixed socket docs are referenced by member hash, not refetched as a new maintenance observation. Newly consulted Python socket.sendto API and Linux send(2) distinguish a syscall return count from receipt and require MSG_DONTWAIT per call to avoid descriptor-alias blocking-mode assumptions. No numerical/learning algorithm or paper result changes.

Choose composition of the actual existing classes, using one supplied socket for both recvmsg and sendto. Reject a caller-generated observed_sim_ns, alternate send socket, new codec, replacement protocol mock or a generic new process-governance layer. An external descriptor_guard(sock) binds the selected socket to its lifecycle; actual kernel provenance remains unverified in this offline stage. The existing backend.observe checks the same expected process/namespace identity at boundaries. Time-of-check/time-of-use races and hostile same-UID mutation are not solved by these observations.

## Interface and lifecycle
ObservedWireSession(process, expected, path, remote_clock, clock_lane, sock, start_ns, journal, descriptor_guard, backend=None) constructs exactly one DatagramReceiver and one OwnedWireBootstrap. Require actual JournaledSimulationClock/RemoteMonotonicClock, matching session IDs, freeze session and both clock origins. Caller supplies the same local monotonic time basis to lane and backend. No replacement of lane/socket/session in place. Constructor creates no UDP socket, binds nothing and starts no process. Supplied socket lifetime remains caller-owned; owned listener connections are closed on refusal through existing close behavior.

poll_listener() advances existing listener phases. poll_datagram() consumes at most one packet only in first_ready/stream_ready, selects a committed independent clock snapshot at reply preparation, records it before forwarding to the existing wire codec, and preserves existing reserved-reply/status500 logic. Empty queue is None, no fabricated event/clock advance. Missing clock, duplicate simulated time, early phase, replay or gap refuses according to existing contracts; no hidden waiting/retry.

Before syscall sendto(raw, MSG_DONTWAIT, peer), recheck socket profile/descriptor guard, frozen clock configuration, same expected owned identity, lane health and the **selected** sample's age/membership. A newer healthy sample cannot freshen an older selected one. Preserve original8s global/2s packet/source bounds, exact local127.0.0.1:14548/peer127.0.0.1:14588,4096bytes,500 modeled samples,25s/1ms lane profile. No network/synchronization/fusion qualification is granted by successful synthetic completion.

Return the raw sendto result immediately to existing wire code so it can record the actual return before later health checks. Short count/BlockingIOError/exception refuse without retry; no claimed rollback. Any subsequent source/clock/journal failure may invalidate the operation but cannot erase a recorded accepted count. Separate outer selection journal from receiver and core logs; no decoder duplication.

## Supporting narrow API additions
- DatagramReceiver.check(): existing clock/descriptor/profile checks without recvmsg or refresh; same operation lock/refusal semantics. Add cheap progress for failure inspection.
- JournaledSimulationClock.validate_selection(selection): guard and freshness, exact observation identity in this lane, timestamp ordering and age of the selected sample and receipt; does not consume/refresh it. Add cheap progress without copying25000 observations.

Outer poll operations serialize with nonblocking lock. Reentry latches refusal and closes existing listener connections; no later send. close during a callback prevents commit; successful completion remains separate from live qualification. Journals/source callbacks may block and need existing outer supervision; arbitrary Python calls are not preempted. A source failure occurring after the final check may race with an in-flight syscall; no impossible atomicity guarantee.
