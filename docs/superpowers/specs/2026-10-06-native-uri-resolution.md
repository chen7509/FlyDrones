# Native URI resolution with original source context

Standing user approval covers this design and inline implementation. Extend the existing read-only C++ resource resolver with `uri KIND SOURCE URI`, where KIND is include, texture, mesh-path, or collada-image. No Server, TestFixture, plugin instance, physics, estimator, renderer or network callback may be created. Keep all capture behavior and thresholds unchanged.

Research: installed Sim8.15/Common5.9/SDFormat14.9 and pinned Apache2 sources remain selected. `sdf::findFile(uri,true,true,config)` then `getModelFilePath` is the include path. Renderer PBR uses `asFullPath(uri,source)` then `common::findFile`; MeshManager likewise calls findFile on the transformed path before decoding. ColladaLoader calls `Material::SetTextureImage(image,meshDirectory)`, which tries the source directory, common finder, then ../materials/textures. Reuse that installed method instead of approximating it. Reject a forced-Assimp profile for this COLLADA-specific path. No pixel or mesh decoding is claimed.

Require existing absolute SOURCE and local nonempty URI (file/model schemes or plain paths); reject remote/unknown schemes, controls and ambiguous whitespace. Preserve lexical source path, native lookup-selected path, canonical selected file, transformation and model.config dependency separately. Run in a short-lived subprocess, record cwd and before/after named lookup environment; `addResourcePaths()` may mutate only that subprocess. Missing/nonregular files and SDK errors fail nonzero. A caught error emits structured JSON with environment context plus stderr and cannot pass as a result. No Fuel fallback is registered.

Native query success proves selection under the supplied original-source context and environment, not rendering, runtime closure, absence of all alternative matches, or capture authorization. Explicitly report ambiguity qualification false. The existing plugin cross-root guard remains unchanged. No graph is allowed into capture based only on these results; a subsequent binding contract must reconcile declared candidate roots, startup selection and lazy/owned process mapping. This separation prevents silently treating the current unique-candidate heuristic as a proven graph.

Tests must distinguish source-directory texture resolution from cwd, include lookup from texture lookup, standard COLLADA fallback from naive concatenation, missing/remote inputs and environment mutation isolation. Use actual installed API executable against real temporary files, retaining per-case outputs. Apply the new modes to the existing frozen PR52 references without rescanning or rerunning SDK installation inventory. Preserve mismatches/refusals. Sources and exact current environment are evidence, never reconstructed historical capture context.
