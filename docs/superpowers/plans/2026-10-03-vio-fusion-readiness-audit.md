# VIO 融合前置审计实现计划

1. 核对 PX4、MAVLink 和 OpenVINS 上游接口要求，冻结当前回放身份、指令速度上限和诊断阈值。先编写规格并记录缺失字段。
2. 先写有意义的失败测试：跳变必须定位到原始帧；缺失协方差/质量/重置/时钟等字段必须拒绝融合；损坏或乱序输入必须失败；现有输出不能覆盖。
3. 实现独立离线审计 CLI，不导入 Gazebo 真值，不发送 MAVLink，也不更改估计器。执行针对性测试、Ruff，再运行冻结回放并保存可重算 JSON。
4. 核对源文件和报告哈希，形成结果报告；复核审计局限、工作树和进程。若确认只是诊断，则以草稿 PR 交付，继续推进协方差/复位信息与标定的后续依赖。
