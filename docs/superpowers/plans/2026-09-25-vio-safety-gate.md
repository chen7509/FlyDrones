# VIO 安全门控实施计划

1. 基线核查：确认现有测试、PX4/Gazebo 进程、上游时间戳与 DDS 能力。
2. 测试先行：视觉流 UDP 监视器对有效、延迟、断流和异常包的行为；控制进程对失效后不再发速度目标、发降落请求的行为。
3. 实现：转发器发送逐帧元数据，压力试验入口为相应控制进程配置监视器，控制循环在规划前门控并记录完整时间线。
4. 回归：运行针对性/全量测试、静态检查、单机基线/120 ms/400 ms PX4/Gazebo 轮次，独立读取 ULog 和转发日志；原始失败全保留。
5. 报告：如实区分视觉输入门控、PX4 EKF 状态、原始测量时间戳和真实相机 VIO 的验证程度。
