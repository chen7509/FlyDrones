# 固定输入 OpenVINS 起飞前状态诊断（2026-10-05）

本阶段确认了预解锁窗口有连续、数值有效的 OpenVINS **内部**状态，但没有取得在线导航或 PX4 融合资格。41 帧预解锁输出的公共 `initialized()` 都为 false。新增的只读诊断不能直接替换飞行门禁。

## 实现、固定条件与失败记录

新 C++ 探针派生 VioManager，只读内部标志、参考时间、状态、零速更新锁存及 IMU 边缘协方差；未修改或重编上游库。输出原生 OpenVINS JPL xyzw 四元数及 15×15 IMU 协方差，不声明 PX4 NED/FRD 坐标、校准后的不确定度或逐帧零速更新事件。初始化内部标志为 false 时向量和协方差写 null。

继续使用 GPL-3.0 的 OpenVINS `69488123ed9362dd44b6f28e7f4680abbff1442b`，库 SHA `532ae57a6a952a0137cc1de291bc47ad556d419c7524fbb23b7a90c00addab5b`；维护情况、接口、替代方案、资源成本见阶段规格。固定 PR #30 的配置、428 张图像和 10711 条 IMU，逐项核对482份来源文件哈希。没有启动 PX4/Gazebo、训练、生成新场景或修改果蝇策略。

## 预解锁窗口与计算成本

独立复核补足两项保护：输出路径现在先拒绝已有对象、悬空符号链接和别名，再使用 Linux 独占、不跟随末级链接的创建方式，并检查写出/关闭错误；窗口首末覆盖改为严格小于一个采样周期，防止少最后一帧的40帧被误放行。另拒绝常规更新时间和移动锁存倒退。全部保留先失败测试，最终 audit-v4 对同一 JSONL 的结论与 v2/v3一致。

本次回放的原生产者保存在证据包 `producer-source-v1.cpp`，SHA `b8f52d6d5dc9c99c6977529f1929085fbf085cb964cc3fd4218e6fb531d6324f`。修订版探针重新编译，但只运行独立输出保护测试，没有再运行估计器。因此旧CSV逐字节一致的实测结论属于原生产者；修订版的新I/O路径已编译并通过普通写入、别名、悬空链接、目录、已有文件、硬链接及文件大小限额写失败测试，完整估计器重放尚未重复。一次构建脚本错误替换了源码文件名而失败，日志保留；修正脚本后的构建成功。原始回放/输入不受影响。

15.68–19.70 s窗口41帧全部通过有限数值、四元数范数、协方差对称/半正定、图像与状态时间误差≤50 ms及相邻图像≤150 ms的诊断筛选。41帧零速更新锁存均为 true、移动标志为 false；锁存值本身不能证明每帧都发生一次零速更新。原生速度范数中位0.0001464 m/s、最大0.0001665 m/s；这是估计器输出，不是独立速度真值。协方差对角上下界全部保存在 summary-v1.json；未完成一致性/可观性校准。

本次离线回放墙钟4.87 s，峰值 RSS 68220 KB。单次 camera API调用中位1.447 ms、P95 3.647 ms、最大32.832 ms；预解锁中位0.777 ms。该计时不包括IMU馈送、图像解码、协方差导出、序列化或传输；单次离线结果不能证明端到端实时能力。它也不是完整果蝇决策耗时，后者上轮中位约370 ms，仍未解决。

## 验证层级和剩余项

已验证：固定输入的只读 CSV 奇偶性、四种时间的区别、起飞前41帧内部状态数值/连续性、离线无效数据拒绝。初次全库602项通过（286.05 s）；复核修订后最终全库 **607项通过**（198.91 s，2条既有警告），Ruff通过。独立复核确认两项Important和一项Minor均已闭环，无剩余Critical/Important。当前新二进制另直接验证了在加载估计器配置前拒绝已有输出，原状态CSV哈希保持不变。

仅实现：只读诊断接口和离线完整性筛选器。`eligible_for_px4_fusion` 始终为 false，未加入任何 MAVLink 发送路径。

未测试：在线输出到达时延、健康/质量与 reset 元数据、坐标与协方差转换、VIO→EKF2闭环、融合退出/恢复、相机/VIO故障注入、陌生自然场景、公平基线、多机扩展、HITL和实飞。

仍失败：上一轮完整果蝇物理飞行碰撞和50 ms决策预算；五机WSL2容量0.873 RTF低于0.95。这些结果不因离线数值筛选通过而改变。本阶段没有新物理飞行；也没有证明完整果蝇自主学习、分工或优于基线。
