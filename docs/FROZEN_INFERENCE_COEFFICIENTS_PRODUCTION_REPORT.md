## Cache and training lifetime

Derived buffers are nonpersistent, with only one current set and one alpha, not a growing interval dictionary. Ordinary source dependency replacement, in-place version changes, dtype/device/shape or mapped-index changes rebuild the cache. The final signature uses weak references checked by object identity plus versions/metadata; it does not prolong a replaced dependency's lifetime or rely solely on recyclable integer ids. No whole-tensor hashing or device-value synchronization is added to that metadata check. `.data`, hostile/concurrent mutation and arbitrary Python provenance are not authenticated.

Training mode, any trainable parameter, or feature/state gradients clear the cache and use the differentiable path. Versionless inference-mode dependencies fall back. Mutable Tensor/array intervals recompute alpha, while immutable scalar type and value are both part of its key. Current whole-module serialization/deepcopy drops ephemeral weakrefs/derived caches in the serialized state without changing the live caller. Official named-parameter checkpoints and state_dict keys do not gain cache parameters or model-identity suffixes. Compatibility with arbitrary historical whole-module pickles is not asserted.

Derived bias/gain vectors and scalar tau/alpha add persistent runtime storage; weakref/version checks also cost CPU.
