# EGO 桥接 CDR 字段的独立离线核验

本阶段在已有摘要关联上增加一个**可选的严格字段核验**。它先执行原桥接日志完整性检查，要求六种预期消息都出现，再用独立的 ROS 2 Humble 类型库解码已保存的 CDR 字节。每条 `/clock`、里程计、触发、相机位姿、深度图的消息时间必须等于日志记录的采样时间；收到的 `PositionCommand` 时间、轨迹号和 READY 状态必须等于单独记录的解码元数据。深度图还需符合现有桥接的 `32FC1`、光学坐标系、步幅和字节数。额外尾部字节、无效时间、错误坐标系、图像几何及非有限命令数值均拒绝。格式检查采用解码后再次序列化的逐字节一致性；这是一项保守的规范化限制，真实 Humble RMW 字节仍需交叉验证。CDR 本身不携带已认证的话题类型；按日志种类选解码器只能证明结构兼容，`ros_topic_type_identity_verified` 保持 false。

依赖选择：固定上游 EGO-Swarm `23a8d5a191711dd65633df689bd00f55d4dea8f9` 为 GPL-3.0，`PositionCommand.msg` 从先前封存源码 ZIP 读取并核对 SHA-256 `9e0e570fa796d18ea4170c569491d1ba6a63daa78007d0d12c3b7b208c597944`。[rosbags 类型系统](https://ternaris.gitlab.io/rosbags/topics/typesys.html)支持 Humble 标准消息和运行时注册自定义 `.msg`；本阶段仅在离线审计的可选依赖中固定 `rosbags==0.11.5`，其包元数据许可证为 Apache-2.0，PyPI 记录该版于 2026-08-19 发布。[ROS 2 Humble `rclpy` 序列化源码](https://github.com/ros2/rclpy/blob/humble/rclpy/rclpy/serialization.py)和[标准 Image 定义](https://github.com/ros2/common_interfaces/blob/humble/sensor_msgs/msg/Image.msg)用于核对接口语义。该纯 Python 库免去本机缺失的 ROS 安装；新增适配为一份离线审计器和可选开关。没有采用自写 CDR 解析器，因为它会复制复杂的类型与对齐逻辑，且难以独立核验。固定 wheel 的 SHA-256 为 `e81bc1bbdadeb1a03cd43f9d67dfb2e17ac9fd5245c8ee5119da72ce8a7ab29b`；隔离安装的运行依赖为 apsw、lz4、numpy、ruamel.yaml、typing_extensions、zstandard。尚未测实际 ROS 节点或新增日志负载。

测试使用 `rosbags` 创建**合成**有效 CDR，覆盖六种消息类型、字段相符、错误元数据、改变编码、多余尾部字节和缺少全部发布消息。最初两个正反例在缺少 `verify_payload_fields` 参数时按预期 RED；独立复核指出命令单独存在也会误报字段覆盖，新增反例 RED 后修复。严格测试依赖已写入 `dev` extra，并在本阶段的隔离环境中实际安装运行；缺依赖时不允许悄悄跳过。复核还指出 CDR 不携带已认证的 ROS 话题类型，因此另加明确的 false 标志，不作类型身份断言。最终六个相邻 EGO 测试文件 **133 passed**，改动 Python 文件 Ruff 与 `git diff --check` 通过；独立再审未发现当前范围余留的 Critical/Important。原来任意字节的合成日志仍可走默认的摘要候选模式，严格模式会拒绝它们。两种模式都保持来源、DDS 交付、规划器消费、ROS 运行时类型支持、话题类型身份、数值等价和教师资格为 false。

**已验证：** 合成 CDR 字段与记录元数据的一致性及上述故障拒绝。**仅实现：** 针对未来真实原始 CDR 日志的可选严格离线核验。**未测试：** Humble `rclpy` 与 `rosbags` 的真实跨运行时字节对照、带补丁的 EGO 二进制、真实 ROS 网络、PX4 EKF2/已标定相机来源、规划数值等价和物理对照。**历史失败仍在：** PX4 首次 2 秒 TIMESYNC 未到、五机相机 0.873 RTF 低于 0.95。当前 Docker 引擎未运行，WSL 没有 ROS；本阶段没有启动 Docker、PX4/Gazebo、OpenVINS 或训练。下一步在资源满足且无竞争时构建固定 EGO 补丁并取得真实 CDR/规划输入及原版数值对照；此前不能把这个字段检查当作合格教师标签。
