# 固定输入50 Hz OpenVINS传播验证（2026-10-05启动）

**在保持10 Hz相机、250 Hz IMU和原配置不变的离线重放中，生成了2,030个有效的50 Hz原生惯性预测，起飞前202个目标全部通过数值/连续性筛选。原10 Hz视觉轨迹CSV逐字节不变。**这补足高频状态输出的一个依赖，但没有建立在线VIO→EKF2闭环，也没有解决果蝇决策慢或碰撞。

## 方法和可复核条件

复用固定OpenVINS GPL-3.0 `69488123ed9362dd44b6f28e7f4680abbff1442b` 的 `Propagator::fast_state_propagate`；上游库SHA `532ae57a6a952a0137cc1de291bc47ad556d419c7524fbb23b7a90c00addab5b`未变。候选库维护情况、版本、许可证、资源和采用/拒绝理由见阶段规格；没有安装ROS、升级库或重写积分器。

新探针为上一阶段C++工具增加可选输出文件：先执行20ms目标时刻的传播，再处理同一时刻的图像。每个目标读取截至其后第一条IMU边界；原始文件有完整4ms步长。所有来源482份文件逐项核对PR30封存哈希。实际只运行一次新阶段重放，输出新目录 `results/openvins-fast-propagation-dev-1701/replay-v1`，未覆盖旧结果、未启动PX4/Gazebo或训练。

全部2,136个目标均记录状态，初始化前106个目标没有预测，保留null和未初始化原因；首次成功为4.72 s，初始化之后2,030次传播全部成功。目标范围2.60–45.30 s、间隔20ms。内部/公共初始化条件保持原语义；起飞前15.68–19.70 s的202个目标公共标志仍全部false，融合资格始终false。

每次传播前后逐值比较滤波时间、IMU状态与边缘协方差，2,136次都未改变相机滤波状态；仅上游传播缓存正常变化。相机输出仍428行，SHA **`2b5ce9c343e63f3178a74e8a02c889beba3bfbc02ddf9eaf4e1c526f94a6f550`** 与前两阶段一致。fast JSONL SHA `19d468a25a2417bab08ebe19f3b00606c8b5b13f788206a0663aacdc752882d4`；实际探针二进制SHA `b9d8b016f17d65f7ae9c93066c53b121772ab4e91ed38cc3f0ee28b94cee3a32`。构建源码、头文件和库哈希均记录。

Ruling：fast模式使用整数纳秒决定IMU截止边界，避免比较浮点秒把边界归错；原默认模式保留原规则。加入传播后的实际相机CSV仍完全一致，证明本固定输入没有因调度改变滤波结果；不推广为所有数据集的等价证明。非零相机/IMU时间偏移明确拒绝，未声称已验证其时间基语义。

## 失败拒绝与验证范围

20项针对性Python测试通过。对实际JSONL的内存副本另注入10种异常：缺少预解锁末目标、未来图像、陈旧滤波时刻、NaN速度、负协方差、缺IMU边界、初始化丢失、非零时间偏移、传播失败、滤波状态被改动，全部被拒绝；原始文件未改。这些是离线数据故障测试，不是实时相机/IMU故障或EKF2恢复实验。最初缺模块的RED日志和旧探针不支持新可选参数的拒绝日志均保留，实际新阶段估计器重放未发生错误。

全库 **627项测试通过**（181.47 s，2条既有警告），Ruff及差异检查通过；独立代码/证据复核未发现Critical、Important或Minor问题。复核没有运行测试或估计器。相关回放、PX4/Gazebo和训练进程检查未发现残留。

已验证：固定输入50Hz原生传播、202个起飞前目标、逐次滤波状态不变、相机CSV奇偶性、上述离线异常拒绝。仅实现：可选原生输出接口和离线审计器。已设计但未实现/未测试：MAVLink坐标及协方差转换、时钟同步、会话重置/quality、消息序列化和在线健康门禁。未验证：在线未解锁影子、VIO→EKF2融合、故障退出/恢复、真实未知场景及公平基线、硬件在环和实飞。

保留原失败：完整果蝇物理回合碰撞、50ms决策预算、五机0.873RTF/0.95门槛。相机/物理负载未降低，没有扩大到20或100机；不会把WSL平台容量失败归为果蝇策略失败。
