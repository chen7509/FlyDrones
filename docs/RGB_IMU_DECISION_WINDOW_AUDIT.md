这个窄门槛说明旧回合的**决策时段**不因启动/退出时的原始帧缺口而需要重复
仿真；它没有使全程采集变为通过。0 ms 最近邻差来自仿真时间网格，不能作为
相机–IMU 时间校准、实际计算延迟或真实 VIO 精度。当前定位和相机位姿仍来自
Gazebo 模型真值；PX4 ULog 无外部视觉融合，五机相机 0.95 RTF 门槛仍失败。

标定方面，目前仓库相机 SDF 只给出单路 160×120、10 Hz、水平视角 1.274 rad
及相对 `base_link` 的名义安装位姿；本机 PX4 `x500_base` 的 IMU 标记为
`base_link`。尚未捕获 Gazebo `camera_info` 的实际内参/畸变、确认光学坐标系
到 IMU 的变换及测量时间偏移。因此尚不能把模型参数直接当作已验证的
OpenVINS 标定文件。下一个独立开发步骤是记录 `camera_info`、解析完整 SDF
坐标链并做图像投影/时间对齐检查，然后才能离线运行固定版本的上游 VIO。
