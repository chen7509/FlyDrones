## 已实现与证据

`configs/connectome_corpus_v2.yaml` 将六阶段各 2 个训练世界、1 个验证世界与每世界 3 个回放种子绑定，合计 54 个作业。配置加载时核验历史正式清单的完整字节 SHA-256 `08ecaa1b433c49630b9beb23c896f57e87fbed4ff1869f0f0b4b250f86a8bac0`、内部封印、20 个世界及正式/开发/训练/验证种子互斥。可追溯副本为 `evidence/fly-ego-formal-seed-manifest-2026-09-22.json`，原始正式证据未改写。配置还核验原始机体及基准配置 SHA-256、固定的六阶段和回放种子、EGO-Swarm 上游提交及历史镜像 ID。正式冻结标识为 `9d10bb72c1fda4048f0439c9dfb823583d8464a8491349f9e732e9cced87d937`，当前配置摘要为 `126e9bbac396c4ef8670ce2f6b85e84d5638fbe0701cf26158c6f4f58252beae`。镜像 ID 来自历史冻结清单；本次 Docker 服务未运行，因此**没有**核验该镜像目前可用，也没有调用 EGO 教师。

世界生成器只接受与配置一致的固定种子，沿用项目既有车辆包络、可通行性和 SDF 物理几何。独立执行了全部 54 个作业的无仿真构建与可通行性检查，得到 54 个不同的 JSON 哈希，与正式世界 JSON 哈希零交集；按边界、起终点、障碍、动态物体和风组成的物理指纹，六阶段训练与验证世界也均无重合。`disturbance` 的物理风会写入 SDF；JSON 内相机延迟、IMU 偏置、深度噪声和有限丢帧目前**只是确定性参数声明**，尚无采集器实施或故障生效证据。

教师序列新增 v2 有效位：每帧只引用实际收到的 EGO `position_ref`，末尾缺少的未来点以零占位并标为无效。写入和回读拒绝非有限参考点、非连续有效位和伪造的非零未来占位；v1 写入路径继续保持原 schema 和数组字段，v1 回读把旧有固定窗口视为全有效。这里还没有真实教师轨迹，测试使用受控的合成参考点验证数据契约。

为后续采集增加 `validate_capture_input()` 前置门：将真实后端自报的定位和相机位姿来源与逐帧证据比对，拒绝 Gazebo 真值、过期或未来的图像及估计、无效 EKF2 状态、未验证相机外参、未核验教师镜像，以及非有限或错误格式的 RGB-D/位姿。历史 `NativeGazeboPx4Backend` 现在明确标为 `gazebo_model_truth`，因此不能通过此门。通过的正例是**合成输入的规则单测**；尚无真正的 PX4 EKF2 证据生产器或采集器调用该门，不能据此称为传感器融合闭环。

代码复核后补充了重新封印但缺世界的正式清单、被替换的教师镜像、配置与生成器种子不一致、训练/验证实际布局重合以及教师未来点伪造等负例。配置与世界测试 30 项、教师轨迹与相邻数据集/录制/训练测试 18 项、采集输入门 16 项通过。加入输入门后的最终全量 Python 回归 **465 通过、1 个既有 MaleCNS 神经元组警告**，耗时 213.87 秒；Ruff 和 `git diff --check` 通过。这些均是单元和无仿真场景检查，并非 PX4/Gazebo 飞行通过。

## 仍关闭的门槛

计划的单回放采集不可直接沿用当前 `NativeGazeboPx4Backend.observe()`：它将 Gazebo 模型真值的位置、差分速度、航向及由真值换算的相机位姿放入控制器 `Observation`。若直接写入学生序列，会违反“部署可见信息”的限制。需要先提供有采样时间、健康与新鲜度检查的非真值估计来源，再在单机开发回合验证；评分器的 Gazebo 真值必须保持只在评分端。相机–IMU 外参和时间偏移也仍是仿真配置的暂定值，未完成标定。只有这些输入门槛及进程所有权、相机扰动生效、教师身份核验通过后，才可进行三个开发场景、54 条正式课程语料封存、完整 MaleCNS 单批训练门检和课程恢复。五机 WSL2 相机容量 0.873 RTF 的 0.95 门槛仍未通过；本阶段没有启动五机测试。
